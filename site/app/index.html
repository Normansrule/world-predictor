    About this terminal

    Two ways to use it

    On the web (this page): nothing to install. GitHub Pages serves the app with the newest weekly forecasts.

    On your computer: the full version runs TimesFM itself and opens this same app. psychohistory app builds it and opens http://localhost:8000.

    Source code and instructions on GitHub. Maintained by @Normansrule.

    How it is scored

    Skill is 1 − error(model) ÷ error("no change"). 80% range: it should catch reality 8 times in 10. Odds score (Brier): 0 is perfect, 0.25 is a coin flip. Backtests never let a model see the future it is tested on.

    Seldon is our own forecaster, built to beat TimesFM: four laws of crowd behaviour (inertia, drift, momentum, reversion, on top of the weekly rhythm) and TimesFM itself in one council. The laws' share of the vote is learned per area from finished windows only; until they have beat TimesFM there, TimesFM keeps the vote. Seldon laws is the same council without TimesFM. Both are scored by the same code on the same windows and are allowed to lose.

    Nothing here is financial advice.

    Follow along

    News feed JSON API

    The feed (Atom, for any feed reader) gets an entry for every newly sealed batch and every week of forecasts that came due. The API is every series' newest sealed forecast as plain JSON, for spreadsheets and scripts. To put one forecast on your own web page, use Embed on its series page.
